// Verbos que usan las lecciones: «infinitivo = traducción».
// Los regulares se conjugan solos (tools/build.py). Solo se escriben a mano los
// tiempos irregulares, tras una barra: «| tiempo: eu, ti, el, nós, vós, eles».
// El presente de subjuntivo sale de la primera persona del presente salvo que se indique.
// Antepretérito, pretérito y futuro de subjuntivo salen de «eles» del pretérito
// (estiveron: estivera, estivese, estiver). El imperativo sale del presente (ti: el sen
// cambios, vós: sen a «s» final); «imperativo: ti, vós» lo cambia e «imperativo: -» lo quita.
// Tiempos: presente, preterito, copreterito, antepreterito, futuro, condicional,
// subxuntivo, preteritosubx, futurosubx, imperativo, infinitivo
